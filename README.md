# Ali and Kensington Solicitors

Responsive one-page website for Ali and Kensington Solicitors, built with semantic HTML, CSS and a small amount of vanilla JavaScript.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Project structure

- `index.html` — page content and structure
- `styles.css` — responsive design system and layouts
- `script.js` — mobile navigation and current year
- `assets/london-hero.jpg` — hero image

## Before production launch

Add the firm's confirmed telephone number, email address, SRA information, privacy policy, legal notices and complaints procedure.
